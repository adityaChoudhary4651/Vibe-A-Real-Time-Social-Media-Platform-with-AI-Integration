# Vibe - Real-Time Social Media Platform

Vibe is a modern, premium, feature-rich real-time social media platform designed for creators and connections.

## Key Features

- **Dynamic Interactive Feed**: Create posts, explore categories, leave comments, and toggle likes.
- **WebRTC voice & video calling**: Make direct audio/video calls directly from message threads.
- **Story Sharing & Highlights**: Post vertical media stories and cluster them as profile highlights.
- **Direct Messaging**: Instant private chat with image attachment, favorite chat status, and batch editing threads.
- **AI Integration**: Ask AI assistant questions and get real-time tailored summaries.
- **Tipping System**: Support creators by sending tips directly to their profiles.

## Technologies

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Framer Motion, Axios, Socket.io Client
- **Backend**: Express, Node.js, MongoDB Atlas (Mongoose), Socket.io, Cloudinary SDK
- **Security & Hosting**: Helmet, Express Rate Limiter, Morgan, CORS Whitelist, Vercel SPA rewritten routes, Render Blueprint YAML deployment specs.
